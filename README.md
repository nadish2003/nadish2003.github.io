# Nadish Sathsara — Portfolio

Responsive, buildless HTML/CSS/JavaScript portfolio. Includes real Movie Booking and CATMS screenshots, technology logos, a wireframe animation, shareable project case studies.

## Preview and edit
Open index.html, or run python -m http.server 4173 in this folder. Edit index.html for page content, style.css for appearance, and script.js for case studies and interactions.

## Accuracy
Movie Booking and CATMS visuals are actual screenshots. SAMS is explicitly labelled as a concept with sample data. Movie project payments are simulated. CATMS is a team project with Nadish's contribution identified separately.

## Publish
Upload this folder's contents to a GitHub Pages repository. Choose Settings → Pages → Deploy from a branch → main → root. The standalone HTML edition embeds local imagery and can alternatively be uploaded as index.html. External Google Fonts and Devicon logos require internet access; fallback fonts and text technology names remain available.

## Share a project
Append #project-movie, #project-catms, or #project-sams to the published homepage URL. Each case study also includes Copy project link.

## Contact and privacy
Contact links open the visitor's email application. No analytics, tracking, contact form, or server is included. The supplied screenshot's browser chrome is hidden by the presentation frame; the original supplied image remains in the source assets.

## Project exploration
Filter projects by web or desktop. Enlarge Movie Booking and CATMS screenshots with View screenshot; Escape closes the preview and restores focus. Case-study close controls remain reachable while scrolling. Canonical metadata, Person structured data, robots.txt and sitemap.xml are included; search indexing is controlled by search engines.
